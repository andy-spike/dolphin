# Visual world: the Inky Learning Workspace

Dolphin's interface is a focused learning workspace. It uses warm paper, true ink, and a restrained Flexoki-derived palette. Figtree supports long-form reading. JetBrains Mono marks code and measured information. Blue signals action, focus, and control. Each Course State uses its own semantic color.

The Course Library is a clear index of Courses and Progress. A Brief reads as a ruled sheet. A Lesson is a well-set reading page with Tutor notes in the margin.

Agent Job activity is honest and legible. Show Syllabus, generation, Harness, and Sandbox progress as it arrives. Do not use a generic SaaS dashboard, terminal styling, or decorative clutter.
