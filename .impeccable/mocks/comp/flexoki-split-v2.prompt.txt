Use case: ui-mockup
Asset type: high-fidelity desktop web app concept comp for Dolphin
Primary request: Design a polished minimalist Course Library for Dolphin, a local app where one Student creates personalized Courses and studies them with a Tutor. This is composition C: a split-view Course browser inspired by excellent desktop productivity software.
Surface structure: 1440x900 desktop viewport. One unified application frame with a 280px left Course pane and a flexible right Course detail pane. At the top of the left pane: small "Dolphin" wordmark, "Course Library", and a compact plus button. Below is a clean vertical list of five Courses. Each item uses text and a tiny progress rule only, with the selected Course marked by a narrow blue line and a very pale neutral background. The right pane begins with a compact utility bar containing the Course Folder path and Course State. The content is centered in the right pane: Topic "Distributed systems for backend interviews", its Goal, three small metadata values for Difficulty, Time Budget, and web search, then a section "Up next" with current Lesson title and a dark "Continue lesson" button. Under that is a minimal Syllabus list of six Lessons with completed checkmarks, the current Lesson in blue, and future Lessons muted. Bottom status line says "Courses stay on this machine."
Style/medium: refined production UI screenshot, crisp flat HTML/CSS feel, quiet desktop product design, influenced by Flexoki. Warm paper #FFFCF0 main ground, neutral left pane #F2F0E5, ink #100F0F, secondary #6F6E69, fine rules #CECDC3. Blue #205EA6 marks selection/current only; green #66800B marks completed Lessons. Sophisticated neutral sans-serif for interface and Course titles; compact monospace only for paths, Course State, and metadata values.
Composition/framing: straight-on full viewport. Dense enough to feel useful, spacious enough to read. Clear pane proportions, impeccable alignment, no floating cards. The Course detail should feel like a document-oriented software surface.
